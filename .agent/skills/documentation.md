# Documentation & Wiki Skill

Guidelines for maintaining internal and external documentation.

## Internal Documentation
1. **README.md**: Central source of truth for users. Update it when features change.
2. **CHANGELOG.md**: Record all non-trivial changes under the appropriate version.
3. **CONTRIBUTING.md**: Update developer-facing instructions when tools/workflows change.
4. **.agent/project.md**: Maintain architecture and task status.

## External Wiki (Sphinx/RST)
Refer to [`.agent/wiki_guidelines.md`](../wiki_guidelines.md) for specialized Sphinx/RST formatting and procedures.

## Maintenance
- Check all internal and external links after updates.
- Verify Markdown and RST syntax.
