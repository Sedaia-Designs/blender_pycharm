Codeberg Snapshot Release

Maintainer workflow for publishing an existing snapshot tag

Scope: validate, build, publish, and verify the snapshot version declared in build.gradle.kts.

1) Derived Release Inputs

The script reads the literal version = "..." assignment from build.gradle.kts and rejects non-snapshot versions. It derives all other names consistently:

Input or outputExample
Gradle version0.7.0-SNAPSHOT
Changelog version0.7.0-Snapshot
Git tagv0.7.0-Snapshot
Release nameBlender Python Development v0.7.0-Snapshot
Distribution assetBlenderPythonDevelopment-0.7.0-SNAPSHOT.zip

2) Prerequisites

  • The matching tag must exist locally and on origin, with both resolving to HEAD.
  • The worktree and index must be clean so the built ZIP corresponds exactly to the tagged commit.
  • CHANGELOG.md must contain a section matching the normalized snapshot version.
  • curl, git, jq, security, and shasum must be available.
  • The Codeberg token must have push permission for SakuraSedaia/blender_pycharm.

Store the token in macOS Keychain without placing it in source files or shell history:

security add-generic-password \
  -a "$USER" \
  -s codeberg-release-token \
  -w \
  -U

3) Release Workflow

First run the local-only check. It reads release metadata and validates the existing tag and artifact without accessing Keychain or Codeberg:

scripts/release-codeberg.sh --check

Publish with full compile, test, plugin build, release creation, asset upload, download, and SHA-256 verification:

scripts/release-codeberg.sh

When the exact distribution ZIP has already been built and validated, the build can be skipped explicitly:

scripts/release-codeberg.sh --skip-build

4) Safety and Idempotency

  • An existing release is reused only when its tag, name, draft state, and pre-release state match.
  • An existing same-name asset is downloaded and hashed; the script never silently replaces it.
  • A missing asset is uploaded once, then downloaded and compared with the local ZIP.
  • The token is read from CODEBERG_TOKEN when set, otherwise from macOS Keychain.
  • The script does not create commits, tags, or remote branch updates.
  • The token is passed to curl through standard input rather than a command-line argument.
Failure behavior: metadata mismatches, missing changelog content, mismatched hashes, or a tag that does not resolve to HEAD stop publication rather than rewriting remote state.
