1) Plugin Registrations

The plugin registers notification groups, tool window, settings configurable, startup activity, new project generator integrations, run configuration type, and debug runner.

2) Service Model

ServiceScopePurpose
LauncherProjectBuilds launch command, renders bootstrap scripts, starts Blender process handler.
BlenderInstallationScannerProjectScans OS-specific paths for Blender installs and updates cache.
ProjectConfigStartupLoaderStartup activityLoads state, ensures runtime extracted, cleans stale scratch bootstrap scripts.
SettingsInstallationScanServiceAppUser-initiated install scan orchestration from settings/tool window.

3) State Model

Persistence is split by ownership:

  • ProjectConfig stores workspace/run behavior and project-local runtime fields.
  • PluginConfig stores global plugin paths, cache settings, and detected installations.
Rule: project-scoped runtime behavior belongs in ProjectConfig; global settings belong in PluginConfig.

4) Runtime Extraction Model

Python runtime resources are versioned and extracted under IDE options path: BlenderDevelopment/DebugRunner/runtime. Extraction is guarded by a version marker .runtime.version bound to plugin version.

5) UI Surfaces

  • Tool window: project workspace editor with autosave and explicit save/reload.
  • Settings: global plugin settings and installation scan action.
  • New Project Wizard: Blender manifest + project template generation flow.
  • Run Configurations: Blender run/debug entrypoint with runtime bootstrap.

6) Complex API Snippets

Project service access pattern

@Service(Service.Level.PROJECT)
internal class Launcher(private val project: Project) {
  companion object {
    fun getInstance(project: Project): Launcher = project.service()
  }
}

Startup initialization flow

override suspend fun execute(project: Project) {
  PluginConfig.getInstance().loadPluginState()
  ProjectConfig.getInstance(project).loadWorkspaceState()
  BlenderRuntimeResources.ensureRuntimeExtracted()
  BlenderBootstrapScriptCleanup.cleanupStaleScripts(...)
}
