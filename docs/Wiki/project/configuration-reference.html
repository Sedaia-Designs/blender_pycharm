1) ProjectConfig

Service scope: project. Storage: $PROJECT_CONFIG_DIR$/blender-workspace.xml.

FieldTypePurpose
blenderPathStringSelected Blender executable or app bundle path.
blenderVersionList<Int>Target Blender version selection.
addonSymlinkNameStringAdd-on symlink/runtime identity for generated scripts.
sourceFolderStringProject source root used by runtime and generator defaults.
runArgumentsStringUser-provided additional Blender CLI arguments.
blenderLogLevelStringLaunch log level mapped to --log-level.
reloadOnSaveBooleanEnables automatic runtime add-on reload on file save while Debug run sessions are active.
justMyCodeBooleanDebugger preference toggle.
extensionsRepositoryStringExtension repository path/URL.
environmentVariablesMap<String, String>Project-scoped env vars for launches.
scriptDirectoriesList<String>?Optional script directory overrides.

2) PluginConfig

Service scope: application. Storage: blender_pycharm.config.xml (application level).

FieldTypePurpose
blenderInstallPathStringGlobal root folder for managed Blender installs.
bpyApiInstallPathStringGlobal location for code-completion stubs.
downloadPathStringTemporary downloads path.
clearDownloadsAfterInstallBooleanCleanup behavior after install.
downloadCacheMaxSizeIntCache size bound (GB).
logPathStringPlugin log output directory.
detectedBlenderList<BlendInstallInfo>Cached discovery results from scan service.
globalEnvironmentVariablesMap<String, String>Global env vars shared across projects.

3) Runtime Usage

FieldRuntime integration
ProjectConfig.sourceFolderUsed by generated launch script, debug path mappings, and runtime reload command target selection.
ProjectConfig.reloadOnSaveRead by BlenderDebugProgramRunner before each file save event to decide whether to trigger runtime reload commands.
ProjectConfig.scriptDirectoriesResolved against project root and passed through BLENDER_PYCHARM_SCRIPT_DIRECTORIES; runtime bootstrap loads each entry when it is an add-on root, otherwise scans one level of child directories for add-on roots; also included in runtime reload target selection.
ProjectConfig.environmentVariablesMerged into Blender launch environment after global plugin variables (project values override on key conflicts).
PluginConfig.globalEnvironmentVariablesBase launch environment for all projects.
PluginConfig.blenderInstallPathIncluded in installation scan as a custom root in addition to OS-default discovery paths.

4) UI Ownership

  • Tool window reads/writes ProjectConfig.
  • Settings configurable reads/writes PluginConfig.
  • Startup loader forces eager load for both states.

5) Complex API Snippets

Project persistent state registration

@Service(Service.Level.PROJECT)
@State(
  name = "BlenderExtensionManifest",
  storages = [
    Storage("$PROJECT_CONFIG_DIR$/blender-workspace.xml"),
    Storage(value = StoragePathMacros.WORKSPACE_FILE, deprecated = true),
  ]
)
class ProjectConfig : PersistentStateComponent<ProjectConfig.ProjectState>

App persistent state registration

@Service(Service.Level.APP)
@State(name = "PluginConfig", storages = [Storage("blender_pycharm.config.xml")])
class PluginConfig : PersistentStateComponent<PluginConfig.PluginState>
