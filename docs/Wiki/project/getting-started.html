2) Setup

  1. Clone repository and open it as a Gradle project in IntelliJ or PyCharm with Plugin DevKit support.
  2. Allow Gradle sync to resolve IntelliJ Platform dependencies.
  3. Confirm generated runtime packaging task is present: packageBlenderRuntime.
  4. Confirm processResources depends on runtime packaging task.
./gradlew tasks --all
./gradlew compileKotlin --no-daemon

3) Running The Plugin

Use Gradle run target to start a sandbox IDE with this plugin loaded.

./gradlew runIde

Inside the sandbox IDE, the plugin surfaces:

  • Tool window: Project Blender Manager
  • Settings page: Tools > Blender Development
  • Run configuration type: Blender
  • New project generator integration for Blender workflows

4) Baseline Validation

Minimum contributor validation flow:

./gradlew compileKotlin --no-daemon
./gradlew test --no-daemon
Note: if tests are skipped during a doc-only change, call that out in change notes.

5) Runtime Packaging Notes

The plugin ships Python runtime support by zipping src/main/blender-runtime into blender-runtime.zip during build. This archive is copied into plugin resources and extracted at startup/run time.

val packageBlenderRuntime by registering(Zip::class) {
  archiveFileName.set("blender-runtime.zip")
  from(layout.projectDirectory.dir("src/main/blender-runtime"))
}

processResources {
  dependsOn(packageBlenderRuntime)
  from(packageBlenderRuntime) { into("blender-runtime") }
}
