Current API (Recommended): PythonPackageManager

Get a manager for a specific SDK:

val manager = PythonPackageManager.forSdk(project, sdk)

Common operations

// list
val installed = manager.listInstalledPackages()
val installedSnapshot = manager.listInstalledPackagesSnapshot()
val outdated = manager.listOutdatedPackages()

// install / update / uninstall
manager.installPackage(installRequest, options = emptyList(), module = null)
manager.updatePackages(*specs)
manager.uninstallPackage("requests", "numpy")

// refresh
manager.reloadPackages()

Notable related API

UI Wrapper API: PythonPackageManagerUI

Use this wrapper for built-in progress and error handling around package operations.

val ui = PythonPackageManagerUI.forSdk(project, sdk)
ui.reloadPackagesBackground()
ui.installWithConfirmation(listOf("requests"))
ui.updatePackagesBackground(specs)
ui.uninstallPackagesBackground(listOf("requests"))

Also available:

  • installPackagesWithModalProgressBlocking(...) for modal UI contexts
  • forPackageManager(packageManager) to wrap an existing manager

Legacy API (Deprecated): PyPackageManager

Deprecated in favor of PythonPackageManager, but still available in source.

val legacy = PyPackageManager.getInstance(sdk)
legacy.install(requirements, extraArgs)
legacy.getPackages()
legacy.refreshAndGetPackages(alwaysRefresh)
