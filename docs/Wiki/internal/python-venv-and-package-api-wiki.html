1) Primary Package Management API

Use PythonPackageManager as the current top-level API.

Key calls

val manager = PythonPackageManager.forSdk(project, sdk)

manager.listInstalledPackages()
manager.listInstalledPackagesSnapshot()
manager.listOutdatedPackages()
manager.listOutdatedPackagesSnapshot()
manager.installPackage(installRequest, options, module)
manager.updatePackages(*specifications)
manager.uninstallPackage(*packages, workspaceMember)
manager.reloadPackages()
manager.syncLocked()

UI wrapper API

val ui = PythonPackageManagerUI.forSdk(project, sdk, sink)

ui.reloadPackagesBackground()

ui.updatePackagesBackground(...)

2) Virtual Environment Creation APIs

Standard virtualenv flow

Entry points:

  • PythonMutableTargetAddInterpreterModel.setupVirtualenv(venvFolder, moduleOrProject)
  • createVenv(...) from python-venv
  • createVenvFromSystemPython(...) for system-python service integration

Core call chain:

  1. EnvironmentCreatorVenv.getOrCreateSdk(...)
  2. setupVirtualenv(...)
  3. createVenv(basePython, venvDir, inheritSitePackages)
  4. Resolve interpreter in the new environment and configure SDK
Uses JetBrains helper zipapps (virtualenv-py3.pyz, legacy virtualenv-20.13.0.pyz) instead of raw python -m venv. Helper selection depends on base interpreter language level.

Activation / environment patching

PythonSdkType.patchCommandLineForVirtualenv(commandLine, sdk)
PythonSdkType.patchEnvironmentVariablesForVirtualenv(environment, sdk)

// underlying behavior
PySdkUtil.activateVirtualEnv(sdk)
